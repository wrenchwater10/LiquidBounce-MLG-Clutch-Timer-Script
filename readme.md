# MLG Clutch Timer

A utility script for LiquidBounce that assists in MLG Clutches everytime (very detectable.. obviously.).

## Features
- **Dynamic Timer Slowdown**: Automatically scales down game speed as you fall, giving you extra reaction time the closer you get to the ground.
- **On-Screen Countdown**: Displays a real time countdown right in the middle of your screen so you know the exact moment to place your clutch.
- **Automatic Reset**: Instantly restores normal game speed upon landing or disabling the module.
- **Settings**: Allows for alot of customization like.. effect height (i guess.).

## Usage
Toggle the module on and fall from any height, time your clutch as the timer hits zero.
